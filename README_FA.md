# اپلیکیشن‌ساز ماژولار — نسخه ۰.۱

این نسخه یک نمونه اولیه وب‌محور برای آزمایش معماری ماژولار است.

## امکانات فعلی
- هسته مرکزی سبک شامل EventBus و ModuleRegistry
- ذخیره محلی پروژه در مرورگر دستگاه
- بوم بصری برای نمایش بلوک‌ها
- افزودن بلوک متن، دکمه، تصویر، فیلد ورودی و کادر
- جابه‌جایی بلوک‌ها با لمس/ماوس
- ویرایش مشخصات و حذف بلوک
- اتصال آزمایشی بلوک‌ها از طریق پورت خروجی

## اجرا
نیازمند Node.js نسخه ۲۰ یا بالاتر:

```bash
npm install
npm run dev
```

برای ساخت فایل‌های وب:

```bash
npm run build
```

## ساختار
- `src/core`: هسته و سرویس‌های عمومی
- `src/modules`: قابلیت‌های مستقل
- `src/ui`: محل توسعه اجزای رابط کاربری

## محدودیت‌های این نسخه
اتصال بلوک‌ها در این نسخه صرفاً به‌صورت گراف پروژه ذخیره می‌شود و هنوز موتور اجرای جریان بین بلوک‌ها، ویرایشگر کد اختصاصی هر ماژول، خروجی اپلیکیشن مستقل و ساخت APK پیاده‌سازی نشده‌اند. این‌ها مراحل بعدی هستند.
